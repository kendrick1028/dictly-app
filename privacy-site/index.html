Dictly 개인정보처리방침

시행일 · 2026년 8월 18일

이현우(이하 “개발자”)는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 이와 관련한 고충을 신속하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다. 이 방침은 iOS 앱 Dictly(이하 “앱”)에 적용됩니다.

요약 — Dictly는 회원가입이 없고, 개발자가 운영하는 서버가 없습니다. 녹음·전사문·시간표 등 모든 데이터는 이용자의 기기에만 저장되며 개발자는 이를 수집하거나 열람할 수 없습니다. 이용자가 직접 API 키를 입력해 클라우드 AI 기능을 켠 경우에만, 해당 내용이 이용자가 선택한 AI 사업자에게 직접 전송됩니다.

제1조 (처리하는 개인정보 항목)

앱은 회원가입 절차가 없으며 이름·이메일·전화번호 등 이용자를 식별할 수 있는 정보를 수집하지 않습니다. 앱이 기기 안에서 다루는 정보는 다음과 같습니다.

항목내용저장 위치
음성 녹음이용자가 녹음한 오디오 파일기기 내 앱 저장영역
전사문·AI 생성물변환된 텍스트, 요약·퀴즈 등 학습 자료기기 내 앱 저장영역
시간표과목명, 강의실, 교수명, 요일·시간기기 내 앱 저장영역 및 위젯 공유용 키체인
API 키이용자가 직접 입력한 AI 사업자 인증키기기 내 키체인(iOS 보안 저장소)
앱 설정전사 엔진, 알림 시점, 위젯 표시 설정 등기기 내 앱 저장영역

위 정보는 모두 이용자의 기기에만 존재하며, 개발자에게 전송되거나 개발자가 접근할 수 있는 경로는 없습니다.

제2조 (개인정보의 처리 목적)

  • 음성 녹음 및 텍스트 변환(전사) 기능 제공
  • 전사문 교정, 요약·퀴즈 등 학습 자료 생성
  • 시간표 관리 및 수업 시작 전 알림 제공
  • 홈 화면 위젯에 시간표 표시

수집한 정보를 광고, 마케팅, 이용자 프로파일링 등 위 목적 외의 용도로 이용하지 않습니다.

제3조 (제3자 제공 및 처리 위탁)

개발자는 이용자의 정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다. 다만 이용자가 설정에서 직접 API 키를 입력하고 클라우드 기반 기능을 선택한 경우에 한하여, 해당 기능 수행에 필요한 음성 또는 텍스트가 이용자의 기기에서 아래 사업자로 직접 전송됩니다. 이 전송은 개발자 서버를 거치지 않습니다.

사업자전송되는 내용개인정보처리방침
OpenAI음성(전사 선택 시) 또는 전사문openai.com/policies/privacy-policy
Anthropic전사문anthropic.com/legal/privacy
Google (Gemini)전사문policies.google.com/privacy

클라우드 기능을 사용하지 않으면 어떠한 데이터도 기기 밖으로 나가지 않습니다. 앱은 Apple 온디바이스 음성 인식, 기기 내에서 동작하는 Whisper 모델, Apple Intelligence만으로도 전사와 학습 자료 생성을 모두 수행할 수 있습니다.

제4조 (보유 및 파기)

모든 데이터는 이용자의 기기에 저장되며, 이용자가 삭제할 때까지 보관됩니다.

  • 개별 노트·시간표는 앱 안에서 직접 삭제할 수 있습니다.
  • 앱을 삭제하면 녹음 파일, 전사문, 시간표, 저장된 API 키가 기기에서 함께 삭제됩니다.
  • 개발자는 별도의 사본을 보관하지 않으므로 파기 요청 대상이 되는 보유 데이터가 없습니다.

제5조 (이용자의 권리)

모든 데이터가 이용자의 기기에 있으므로, 이용자는 앱 내에서 언제든지 데이터를 열람·수정·삭제할 수 있습니다. 개발자가 보관하는 개인정보가 없어 별도의 열람·정정·삭제·처리정지 청구 절차는 필요하지 않습니다. 관련 문의는 제8조의 연락처로 하실 수 있습니다.

제6조 (기기 권한)

권한사용 목적거부 시

각 권한은 iOS 설정 앱에서 언제든지 변경할 수 있습니다.

제7조 (안전성 확보 조치)

  • API 키는 iOS 키체인에 저장되며 앱 외부에서 접근할 수 없습니다.
  • 녹음 파일과 전사문은 iOS 앱 샌드박스 안에 저장되어 다른 앱이 접근할 수 없습니다.
  • 클라우드 기능 사용 시 통신은 HTTPS로 암호화됩니다.
  • 개발자가 운영하는 서버·데이터베이스가 없어 외부 유출 경로가 존재하지 않습니다.
