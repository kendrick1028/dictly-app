# 004 · [P1] MemoView 빈상태가 없는 버튼을 가리킴 + 문구 중복

**우선순위**: 높음. **난이도**: 소. **의존**: 용어(task 005)와 문구가 겹치므로, 005 확정 전이면 "새 노트"(현재 실제 버튼 라벨)에 맞춰만 두고, 005에서 최종 조정.

## 문제
`src/renderer/src/components/MemoView.tsx:38-39` 빈상태가 "왼쪽의 "새 메모" 버튼으로 시작하세요"라고 하지만, 실제 사이드바 버튼 라벨은 "새 노트"뿐이다(`grep '새 메모'` 결과 이 한 줄만 존재). 사용자는 없는 버튼을 찾게 된다. 또한 위·아래 두 줄이 의미상 중복이다:
```
<p className="text-[15px]">메모를 선택하거나 새 녹음을 시작하세요</p>
<p className="mt-1 text-[13px]">왼쪽의 "새 메모" 버튼으로 시작하세요</p>
```

## 정확한 변경
사이드바의 실제 CTA 라벨과 일치시키고 한 줄 군더더기를 제거한다. 현재 사이드바 라벨이 "새 노트"이므로(변경 전 기준):
```
<p className="text-[15px]">왼쪽 “새 노트” 버튼으로 첫 강의를 시작하세요</p>
<p className="mt-1 text-[13px] text-subtle">또는 기존 항목을 선택하세요</p>
```
(정확한 최종 문구는 task 005 용어 확정에 맞춤. 핵심은 **실제 버튼 라벨과 일치** + **중복 제거**.)

## 건드리지 말 것
- MemoView의 나머지 로직/레이아웃.
- 사이드바 버튼 자체(라벨 변경은 task 005 소관).

## 수용 기준
- 빈상태 안내가 화면에 실제 존재하는 버튼 라벨을 가리킨다.
- 안내가 한 가지 행동만 명확히 지시(중복 문구 없음).

## 검증
`grep -rn '새 메모' src/renderer` → 결과 없음. `npm run typecheck` 통과. 빈 상태(메모 미선택)에서 문구 확인.
