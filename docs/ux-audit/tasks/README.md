**결정 필요**: 하나의 "강의" 엔티티를 부를 단일 사용자 대면 이름(추천 "강의" 또는 "녹음"), 필기(TipTap)를 부를 단일 이름(추천 "노트"), 스튜디오 저장물 이름(추천 "학습 자료"). `전사문`은 강의의 *탭 이름*으로만.
**치환 대상(REPORT P1-5 근거)**: `MemoView.tsx:99`, `Sidebar.tsx:328,434,445,545,560`, `FolderView.tsx:116,123`, `Spotlight.tsx:26`, `ChatView.tsx:314,318`, `notes/NotesNav.tsx:92,94`, `notes/NoteEditor.tsx:57`, `SettingsModal.tsx:204`, `studio/studioMeta.tsx:20`, `StudioHub.tsx`(‘스튜디오 메모’). "새 노트" CTA가 두 객체를 만드는 문제(강의 생성 vs 필기 생성) 분리. 아이콘 고정: 강의=`AudioLines`, PDF=`FileText`, 필기=`StickyNote`.
**수용**: 한 엔티티=한 이름=한 아이콘. `메모(필기)` 같은 괄호 해명 소멸. **파괴적 아님이나 광범위 → 결정 확정 후 한 번에.**

## 006 · [P1] 타이포 스케일 정의 (디자인 결정)
현재 `text-[Npx]` 19종(9~30px, 반계단 다수). 6~7단계 시맨틱 스케일 확정(예: 11 caption / 12 label / 13 body / 15 title / 18 heading / 23 display) 후 반계단(10.5/11.5/12.5/13.5/14.5)부터 가장 가까운 단계로 흡수. Tailwind `theme.fontSize` 확장 또는 소수 유틸. **점진 적용 가능** — 우선 반계단 제거 → 이후 전면 정리. 회귀 위험 낮으나 시각 확인 필요(스크린샷).
